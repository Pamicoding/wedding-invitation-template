## 照片規格建議

### 尺寸
- **推薦寬度**：1200-2000 像素
- **最小寬度**：800 像素
- **縱橫比**：3:2 或 4:3（橫向）、2:3（直向）

### 檔案格式
- **推薦格式**：JPG
- **替代格式**：PNG（檔案會較大）

### 檔案大小
- **每張照片**：建議壓縮至 500KB 以下
- **最大大小**：不超過 2MB

### 壓縮工具推薦
- [TinyPNG](https://tinypng.com/) - 線上壓縮工具
- [Squoosh](https://squoosh.app/) - Google 的圖片壓縮工具
- [ImageOptim](https://imageoptim.com/) - Mac 專用

## 照片品質建議

1. **光線充足**：選擇光線明亮、清晰的照片
2. **構圖良好**：避免過於雜亂的背景
3. **情感自然**：展現真實的情感和互動
4. **風格一致**：盡量選擇色調和風格相近的照片

## 臨時替代方案

如果某個檔案不存在，網站會自動顯示灰色 placeholder，上面寫著「照片即將上傳」。

這不會影響網站的其他功能，你可以：
1. 先部署網站
2. 後續再逐步上傳照片
3. 照片上傳後會立即顯示

## 上傳步驟

1. 將照片重新命名為上述檔案名稱
2. 確認照片已經過適當壓縮
3. 將照片放入此 `images/` 資料夾
4. 提交到 git 並推送到 GitHub
5. 等待 GitHub Pages 更新（通常需要 1-5 分鐘）

## 範例照片

如需測試網站，可以暫時使用免費圖庫的照片：
- [Unsplash](https://unsplash.com/s/photos/wedding)
- [Pexels](https://www.pexels.com/search/wedding/)
- [Pixabay](https://pixabay.com/images/search/wedding/)

記得使用時要遵守授權條款，且正式上線前替換成你們的真實照片。

## 注意事項

⚠️ **隱私提醒**：上傳到 GitHub 的照片會是公開的，任何人都可以透過網址存取。如果你想保護照片隱私，建議：
1. 在照片上加浮水印
2. 使用較低解析度的版本
3. 考慮使用私有圖床服務（如 Cloudinary, ImgBB 等）

## 問題排解

**照片顯示模糊**
- 檢查原始照片解析度是否足夠
- 確認壓縮時沒有過度降低品質

**照片無法載入**
- 確認檔案名稱完全正確（包括大小寫）
- 確認檔案格式為 .jpg 或 .png
- 確認檔案已成功上傳到 images 資料夾

**照片載入太慢**
- 確認照片已壓縮至 500KB 以下
- 考慮使用 WebP 格式（需修改 HTML）
